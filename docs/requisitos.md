# Requisitos del sistema Prestige Motors

## Requisitos funcionales
- RF1: Consultar el catálogo de vehículos con filtros (texto, tipo, marca, año, precio).
- RF2: Ver el detalle de un vehículo.
- RF3: Registrar una solicitud de mantenimiento.

## Requisitos no funcionales
- RNF1: Backend en Java 17 con Spring Boot y MySQL.
- RNF2: API REST en formato JSON.
